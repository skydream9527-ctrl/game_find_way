## 🎮 Game Overview

A puzzle and maze-solving Android application where players navigate through grid-based maps using pathfinding algorithms (A*, BFS/DFS).

## 🛠️ Build & Run

Open in Android Studio and run on an Android 7.0+ device or emulator.
